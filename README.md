## ✦ Key Features

### 1. Real 3D WebGL Crystal (`HeroScene.tsx`)
- High-performance Three.js refractive faceted crystal with dynamic mouse parallax, floating inertia, and iridescent chromatic aberration.
- **120Hz GPU Optimization**: Automatically pauses the 3D render loop via `IntersectionObserver` when scrolled off-screen, dropping GPU usage to 0% and enabling buttery smooth 120 FPS scrolling across the rest of the site. Adaptive DPR (`1.0` on mobile, capped at `1.5` on desktop).

### 2. Top-Left Logo & Luxury Feature Tray (`FeatureTray.tsx`)
- Clicking the `[ PANEL ]` trigger beside the AVORA logo opens an expandable creative control panel:
  - **EXPLORE**: Instant navigation to Home, Services, About AVORA, Playground, Consultation, Contact.
  - **SERVICES**: Direct access to all 7 disciplines.
  - **START**: Quick-action cards for *Start a Project*, *Book a Consultation*, and direct email.
  - Full keyboard accessibility (closes on `ESC`), click-outside detection, and full-screen mobile adaptation.

### 3. 7 Service-Specific Personalized Consultation Forms (`Consultation.tsx`)
- Replaces generic contact forms with **7 tailored multi-step consultation flows**, each designed for the specific needs of that discipline:
  - **Logo Design**: `LET'S DESIGN YOUR LOGO.` (Logo type, brand personality, color preferences, usage, budget)
  - **Branding**: `BUILD YOUR BRAND.` (Brand story, identity status, applications, guidelines)
  - **Graphic Design**: `LET'S CREATE THE VISUAL.` (Poster, social, campaign, dimensions, copy, visual style)
  - **Apparel Design**: `LET'S DESIGN WHAT PEOPLE WEAR.` (Garment types, print placement, streetwear style, volume)
  - **UI/UX Design**: `LET'S DESIGN THE EXPERIENCE.` (App/SaaS/Dashboard, user problem, wireframes, dev needs)
  - **Web Design**: `LET'S DESIGN YOUR WEBSITE.` (Website type, purpose, pages, visual direction, features)
  - **Web Development**: `LET'S BUILD IT.` (Tech stack, architecture, APIs, CMS, deployment timeline)
- Celebratory confetti feedback and explicit confirmation notice (response within 24–48 hours).

### 4. Dedicated Full About Page (`/about` — `AboutPage.tsx`)
- Accessible via `/about` or by clicking `More About AVORA ↗`:
  - **The Founder**: Honest profile of **Kumar Shaurya** — Multidisciplinary Designer & Web Developer (zero fake awards, zero fabricated client statistics).
  - **Why AVORA Exists**: In-depth narrative on bridging the gap between designers who can't code and developers who can't design.
  - **7 Visual Service Deep Dives**: Detailed deliverables, instruments, and interactive flowcharts for every discipline.
  - **8-Step Creative Process**: 01 Discover → 02 Define → 03 Explore → 04 Design → 05 Refine → 06 Build → 07 Test → 08 Deliver.
  - **Where Ideas Come From**: Architectural pacing, contemporary editorial, streetwear graphics, and digital ergonomics.
  - **Transparent Disclosures**: Clear explanations on using templates/scaffolding for rapid prototyping, and using AI as an accelerator for ideation without replacing human design judgment.
  - **Canva Visibility**: Prominently featured in Graphic Design and Branding workflows.

### 5. Curated Packages (`Packages.tsx`)
- Highlighting **DIGITAL PRESENCE** as the `MOST POPULAR` tier (UI/UX, Website Design, Responsive System, and Web Development handoff).

### 6. Interactive Command Palette (`⌘K` / `Ctrl+K`)

## ✦ Getting Started Locally

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm (v9.0.0 or higher)

### 1. Clone the Repository
```bash
git clone https://github.com/Kshaurya-07/Avora.git
cd Avora
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production
```bash
npm run build
```
Build output is generated into the `dist/` directory with optimized vendor chunking.

## ✦ Deployment on Render

This project includes a pre-configured [`render.yaml`](./render.yaml) for **1-click automatic deployment** as a Render Static Site:

1. Sign in to **[Render](https://render.com)** with your GitHub account.
2. Click **New +** → **Static Site**.
3. Select your repository: **`Kshaurya-07/Avora`**.
4. Confirm build settings:
   - **Build Command**: `npm install && npm run build`
   - **Publish Directory**: `dist`
5. Render automatically applies the SPA routing rewrite rule from `render.yaml` (`/*` → `/index.html`) so `/about` works seamlessly on page refreshes.
6. Click **Create Static Site**.
